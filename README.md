# 심민용 포트폴리오

커피·화장품 브랜드 인하우스 마케터의 포트폴리오 사이트입니다.
브랜드를 세우고, 온·오프라인에서 팔고, 구매 데이터로 확인한 과정을 케이스로 정리했습니다.

**사이트** https://minyongsim.github.io/portfolio_sim2026/
**이력서** https://minyongsim.github.io/portfolio_sim2026/resume.html

## 구성

| 페이지 | 내용 |
|---|---|
| ABOUT | 한눈에 보는 요약 |
| BRANDING | 신산커피 브랜드 론칭·패키지 리뉴얼 / 메르디센트 글로벌 판매 채널 구축 |
| DATA & CRM | '이달의 프래그런스' CRM 캠페인 / 박람회 구매 전환 검증 |
| MARKETING | 담당 범위, 채널별 판단 기준, 지역 키워드 SEO |
| RESUME | 웹 이력서 (PDF 저장 가능) |

## 만든 방식

기획·카피·디자인·코드까지 직접 작업했습니다.

- HTML · CSS · JavaScript (jQuery), GitHub Pages 배포
- 320px 모바일부터 PC까지 반응형
- 스크롤 등장 모션 — 시스템의 '모션 줄이기' 설정을 켜면 모두 정지
- 공통 헤더·푸터는 `js/partials.js` 한 곳에서 관리
